# 🧠 Aether AI – Smart Voice Assistant

## Description
Aether AI is a Python-based smart voice assistant designed to perform daily tasks through natural voice interaction. It uses speech recognition and text-to-speech technologies to respond to user commands for weather updates, system operations, and general information.

## Features
- 🎙️ **Voice Commands** – Recognizes and executes spoken instructions  
- 🌦️ **Weather Updates** – Provides real-time weather information  
- 🕐 **Time & Date** – Announces current time and date  
- 🔊 **Text-to-Speech** – Conversational responses using `pyttsx3`  
- 🌐 **Web Search** – Opens websites or performs quick online lookups  
- 📋 **Task Automation** – Opens apps, searches online, and more  

## Technologies Used
- **Python 3.x**  
- **SpeechRecognition** – for processing voice input  
- **pyttsx3** – for text-to-speech output  
- **APIs (OpenWeatherMap, etc.)** – for live data fetching  
- **datetime, os, webbrowser** – for system-level automation
